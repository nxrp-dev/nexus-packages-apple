# AppleLocale

Core Foundation locale settings and wide-string support.

Moved unchanged from NexusFPC `packages/iosxlocale` on 2026-10-16.
The owner explicitly skipped code review for this relocation. Original source,
namespace wrappers and notices are preserved, with a hashed untouched snapshot
in `migration/`. Canonical credit, source revision, import evidence and licensing
are in [Nexus attributions](../../../ATTRIBUTIONS.md#apple-platform-packages).

`Package.nxscript` declares `NXRP.Apple.AppleLocale`.
`AppleLocale.nxproject` builds 2 ordinary unit roots and their implicit dependencies.
Namespace wrappers are retained for separate namespace consumers.

See the [repository build instructions](../README.md) and
[migration results](../MIGRATION.md).
